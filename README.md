# Lost in the Woods — Interactive Discovery Web Game

An interactive, choice-driven web text adventure built for a class assignment. Players navigate through a mysterious forest, manage inventory resources, and solve puzzles to escape safely.

---

## Features
* **Choice-Driven Narrative:** Interconnected scenes (*Forest, Crossroads, Cabin, River*) with multiple branching paths.
* **Inventory & Resource Management:** Track critical items (Flashlight, Map, Code `7849`) and phone battery life.
* **Cinematic Dark-Mode UI:** Immersive design utilizing custom web fonts and `.avif` visual assets.
